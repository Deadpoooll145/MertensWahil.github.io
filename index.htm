Navigation Autonome TurtleBot

SAÉ 5.01 - BUT 3

Objectif

Programmer un robot mobile TurtleBot pour qu'il se déplace de manière autonome d'un point A à un point B dans un environnement inconnu.

Technologie

  • Capteur : Lidar 360° pour la détection d'obstacles et la cartographie (SLAM).
  • OS : ROS (Robot Operating System) sur Raspberry Pi.
  • Navigation : Utilisation de la Navigation Stack pour la planification de trajectoire.
  • Langage : Python pour les scripts de contrôle.

Objectif du Projet
